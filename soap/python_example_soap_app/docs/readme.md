Sample SOAP Application

### Requirements:
- `python 3.11.4`
- dependencies for server:
  - `spyne`
  - `lxml`
- dependencies for client:
  - `zeep`

### Run Server 
- Navigate to `src` directory.
- To run server:
  </br>
  `python server.py`

## Run Client
- To run client program:
  </br>
  `python client.py`
- To invoke by `curl`:
  </br>
  Naviagete to `docs/curls` and check the `.sh` files.
